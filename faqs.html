Perguntas frequentes

Tire suas principais dúvidas sobre o KiNutri.

O KiNutri usa backend?

Não. Esta versão funciona com HTML, CSS, JavaScript e LocalStorage.

Como o plano é calculado?

O sistema usa cálculos simples baseados no peso informado pelo usuário.

Existe área administrativa?

Sim. Usuários do tipo nutricionista/admin acessam o painel administrativo.

Posso editar meu perfil?

Sim. Na área do usuário é possível alterar nome, e-mail, peso, altura e idade.

Os dados ficam salvos?

Sim. Os dados ficam salvos no navegador usando LocalStorage.

É responsivo?

Sim. O layout foi pensado para funcionar em desktop, tablet e celular.
