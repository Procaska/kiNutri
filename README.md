# KiNutri

KiNutri é um micro SaaS de nutrição desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades

- Cadastro e login
- Área do usuário
- Área administrativa
- CRUD de usuários
- CRUD de planos
- CRUD de alimentos
- Geração automática de plano alimentar
- Dashboard com gráficos
- Dark mode
- Exportação de dados
- Notificações
- LocalStorage como banco de dados

## Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla
- LocalStorage
- Chart.js

## Como executar

1. Extraia os arquivos
2. Abra o `index.html`
3. Utilize normalmente
