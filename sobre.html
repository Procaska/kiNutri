Sobre o KiNutri

Automação simples para planos alimentares personalizados.

Nosso objetivo

O KiNutri foi criado para facilitar a geração de planos alimentares de forma rápida, organizada e acessível.

Para usuários

Usuários comuns conseguem criar conta, informar seus dados e receber um plano nutricional automático.

Para nutricionistas

Nutricionistas podem gerenciar usuários, alimentos e planos dentro de uma área administrativa.
